markdown/tables

Leading ` ` is required, so this doesn't (quite) work:
a b

c|d
 

But this works:

a b
c d

 

Tailing | is optional, except for empty titles:

c d

 

And alignment syntax is allowed:

left center right
loong short looong

 

Extended tables are supported:
 

H1 H2 H3
This cell spans 3 columns

 

H1 H2
This cell
spans three
rows 		Cell A
Cell B
Cell C

 

This header spans two
columns and two rows 		Header A
Header B
Cell A Cell B Cell C

 

And column widths as percentages in the alignment row:
 

Name Notes
short the wide column
