features/_listen tag enables code to be evaluated on certain events:

  • _on_change(text) is evaluated at each change to MindBox triggered by user typing in, or programmatically. Text can be empty.
  • _on_search(text) is evaluated at each new search via MindBox triggered by user typing in (subject to debounce), or programmatically. Search text can be empty.
  • _on_create(text) is evaluated each time new text is submitted on MindBox using create button, keyboard shortcut, or programmatically.
  • _on_command_<name>(`…`) is evaluated when command /name … is submitted on MindBox. Argument … can be empty. Valid return values are in listed in commands.
  • _on_focus() is evaluated each time MindPage window (or tab) is "focused" to receive keyboard, touch, or other input.
  • _on_item_change(id, label, prev_label, deleted, remote, dependency) is evaluated at each change to an item or its dependencies.
  • _on_local_store_change(id) is evaluated at each change to local_store of an item.
  • _on_global_store_change(id, remote) is evaluated at each change to global_store of an item.
  • _on_attr_change(id, remote) is evaluated at each change to attr of an item.
  • Example code: 

function
_on_search(text) { alert("You searched for: " + text) }
function
_on_create(text) { alert("You created: " + text) }
