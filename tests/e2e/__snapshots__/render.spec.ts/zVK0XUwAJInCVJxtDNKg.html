MindPage/core/commands are:

  • _signin new user.
  • _signout current user.
  • _undelete recently deleted items (in current session).
    • Creates new item with identical text as deleted item.
  • _duplicate selected (editing) item.
    • Simple built-in version of commands/copy.
  • _dependencies of selected (editing) item, listed in new item.
    • Also listed below each item. See dependencies.
  • _dependents of selected (editing) item, listed in new item.
    • Also listed below each item. See dependencies.
  • _invert colors.
  • _zoom [factor] page.
  • _reload page.
