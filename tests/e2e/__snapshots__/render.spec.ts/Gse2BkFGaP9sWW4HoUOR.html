MindPage/core/functions/_modal opens a modal window for basic confirmation and input prompts. Programmable click handlers can be used to trigger certain actions that can otherwise be disallowed in some browsers (e.g. iOS Safari), such as:

  • window.open for API authorization (OAuth) flows, e.g. gapi.
  • HTMLElement.focus to focus on input elements, e.g. example:

Can be closed or updated using global functions _modal_close([modal],[output]) and _modal_update(modal, options). Visibility can be checked using _modal_visible([modal]).
Can also be used to work around a known issue with alert/confirm/prompt dialogs not working after using browser history (e.g. going back/forward) in iOS. _modal_alert(msg, [done]), _modal_confirm(msg, [confirmed], [cancelled]), and _modal_prompt(msg, [default], [confirmed], [cancelled]) can be used as convenient async replacements.
