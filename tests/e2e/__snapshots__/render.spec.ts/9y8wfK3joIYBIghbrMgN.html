commands are code run via MindBox. Examples: hello hello_again js alert copy export restore agenda invert weight.

  • Type command as /name … and hit ⇧⏎.
  • Evaluates run(`…`) from item named #commands/<name>.
    • If missing, evaluates _on_command_<name>(`…`) in listeners.
    • Function can be async or return promise, e.g. agenda.
  • Return nothing (or undefined) to clear text and defocus.
  • Return string (can be empty) to replace text.
  • Return object { text:"…" } to create new item.
    • edit:true|false to start editing created item.
    • run:true|false to run js_input in item.
    • init:(item)=>{...} to initialize item.
  • Return null or _Item to do nothing.
    • Allows command to handle any changes to MindBox as needed.
  • Commands can also be triggered programmatically.
    • e.g. via window._create or MindBox.create.
    • Any created or returned _Item (or null) is also returned to the programmatic context where command is triggered.
