MindBox is the multi-purpose text box at the top of the page.

  • Type anything to search for existing items.
  • Tap create or hit ⇧⏎ to create new item.
  • Run code via commands.
  • Use programmatically: init
    • Available as MindBox (or window.MindBox)
      • Also import as #_MindBox to auto-update.
    • Functions (edit for source): get(), set(text), clear(), toggle(text), focus(), create(text,[options]), elem (property)
