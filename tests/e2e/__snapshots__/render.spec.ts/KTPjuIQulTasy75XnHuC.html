Features/_style tag designates the item as a style item such that its css_style block is automatically installed/updated on the page (under <head><style …>). In addition, any dependents of the style item are automatically styled (on their <div class="item …">) using a special CSS class name derived from the style item name as in dep_<name>. Any invalid characters (outside [A-Za-z0-9_]) are replaced with _.
