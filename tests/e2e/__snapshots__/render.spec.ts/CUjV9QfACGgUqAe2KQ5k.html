util/core/array defines array-related utilities.

array ( [J],[x] ) ( [J = 0],[x] )

array xJ of length J


x can be given to fill as xJ[j]=x ∀j
x can be a function of index, e.g. j=>j
same as Array.from(…) if first argument is not a number
zeroes (J) (J)

array(J, 0)

ones (J) (J)

array(J, 1)

fill (xJ,x,[js],[je] ) (xJ,x,[js = 0],[je = J] )

fills xJ as xJ[j]=x ∀j


x can be a function of index, e.g. j=>j

remove (xJ,[x],[js],[je] ) (xJ,[x],[js = 0],[je = J] )

removes all x from xJ


x can be a predicate (boolean) function (xj,j)=>…
x can be undefined (or omitted)
uses === for comparisons
copy (xJ,[yJ],[f],[g] ) (xJ,[yJ],[f],[g] )

copies xJ into new array


can copy yJ into existing xJ
can map copied elements as f(x,j,yJ)
can filter copied elements via g(x,j,yJ)

copy_at (xJ,yK,[js],[ks],[ke] ) (xJ,yK,[js = 0],[ks = 0],[ke = K] )

copies yK[ks…ke-1] into xJ[js…]

each (xJ,f,[js],[je] ) (xJ,f,[js = 0],[je = J] )

invokes f(x,j,xJ) for each x in xJ

scan (xJ,f,[js],[je] ) (xJ,f,[js = 0],[je = J] )

invokes f(j,x,xJ) for each x in xJ

repeat (J,f) (J,f)

invokes f(j,J) for j=0,…,J-1


stops early if f returns null

map2 (xJ,yJ,f,[js],[je] ) (xJ,yJ,f,[js = 0],[je = J] )

maps yJ into xJ as f(x,y,j,xJ,yJ)

apply (xJ,f,[js],[je] ) (xJ,f,[js = 0],[je = J] )

applies f(x,j,xJ) to xJ

swap (y,y_x) (y,y_x)

swaps x<=>y as x = swap(y, y=x)


apply+swap can be faster than map or copy
e.g. xJ = swap(apply(yJ,y=>y*y), yJ=xJ)
