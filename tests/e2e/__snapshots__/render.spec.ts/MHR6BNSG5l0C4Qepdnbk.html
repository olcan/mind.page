util/sample/examples/3 Sample A∈(0,1), B∈(a,1), C∈(a,b). Confine C∈(.4999,.5001) using domain within(.5,.0001). Distances distance(x,dom) are used for guidance when x∉dom, which can be critical for rare domains that are unlikely to contain any prior samples. Distances are not defined for all values or domains (e.g. because there may be no sensible default notion of distance), but are defined for all domains over finite numbers (-∞,∞) ≡ {is:'finite'} as minimum distance |x-y| over y∈(.4999,.5001). Other measures of distance (or methods of guidance) can be used, see 8.


const a = sample(between(0, 1))
const b = sample(between(a, 1))
const c = sample(between(a, b))
// condition(c > .4999 && c < .5001)
confine(c, within(.5, .0001))
