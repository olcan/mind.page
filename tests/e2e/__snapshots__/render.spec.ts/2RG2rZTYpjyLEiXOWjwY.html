commands/export command /export downloads a MindPage.zip file containing all of your items as plain text files:

  • Files are named by position (e.g. 000001) and dated by last interaction time.
  • Uploaded images are placed in a corresponding directory (e.g. 000001/*.jpg).
  • Default extension is .markdown since items often contain Markdown formatting.
    • Specify any extension as /export [extension], e.g. /export txt.
  • All content is fully decrypted and thus no longer protected by your secret phrase.
  • Uses MindPage/core, JSZip, and FileSaver.
    • Edit (tap) this item for full source code.
