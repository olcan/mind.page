features/_init tag enables initialization code.

  • _init() function is evaluated once during page load.
    • Read from js_init block if it exists (otherwise from js).
    • Ignores dependencies (assumed self-contained).
  • Ideal for extending external libraries (e.g. c3, graphviz).
  • Ideal for triggering load for dynamically loaded libraries.
  • New or modified _init functions require reload to take effect.
  • Example initialization code: 

function
_init(
) { console.log("Welcome to MindPage!") }
