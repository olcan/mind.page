util/stat defines statistical utilities.

random ( ) ( )

Math.random on (0,1), excluding 0

random_boolean ( [p] ) ( [p = 0.5] )

random() < p

random_binary ( [p] ) ( [p = 0.5] )

(random() < p ? 1 : 0)

random_uniform ( [a],[b] ) ( [a],[b] )

uniform on (0,1),(0,a), or (a,b)

(0,1) if a and b omitted
(0,a) if b omitted
(a,b) otherwise
random_uniform_array (xJ,[a],[b] ) (xJ,[a],[b] )

fills xJ with random_uniform(a,b)

random_discrete_uniform ( [a],[b] ) ( [a],[b] )

uniform on {0,1},{0,…,a-1}, or {a,…,b}

{0,1} if a and b omitted
{0,…,a-1} if b omitted
{a,…,b} otherwise
random_element (xJ) (xJ)

xJ[random_discrete_uniform(xJ.length)]

random_discrete_uniform_array (xJ,[a],[b] ) (xJ,[a],[b] )

fills xJ with random_discrete_uniform(a,b)

random_discrete (wJ,[sum_wj] ) (wJ,[sum_wj] )

discrete on {0,…,J-1} w/ prob. P(j)∝wJ[j]


faster if wJ is sorted by decreasing weight
normalizer sum_wj can be passed if known
≡ random_discrete_uniform(J) if sum_wj==0
assumes wj>=0 and sum_wj>=0

random_discrete_array (jK,wJ,[sum_wj] ) (jK,wJ,[sum_wj] )

fills jK with discrete(wJ, sum_wj)


faster if wJ is sorted by decreasing weight
normalizer sum_wj can be passed if known
≡ random_discrete_uniform_array(jK, J) if sum_wj==0
indices jK are ordered due to sampling method
use random_shuffle(jK) for random ordering
