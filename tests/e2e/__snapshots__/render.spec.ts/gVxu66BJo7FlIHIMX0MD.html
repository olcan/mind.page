MindPage/core/_Item object holds a reference to a MindPage item and provides access to a wide range of properties and functions:

  • eval([js, options]) evaluates code in context of item.
  • eval_macros(text, [options]) evaluates macros in given text.
  • read([type, options]) reads text from item.
  • read_deep(type, [options]) reads text from item + dependencies.
  • read_input(type, [options]) reads input from item + dependencies.
  • write(text, [type], [options]) writes text into item.
  • clear(type) clears blocks in item.
  • remove(type) removes blocks in item.
  • delete([confirm]) deletes item.
  • get_log([options]) returns console log messages for item.
  • write_log([options]) writes log messages into item.
  • show_logs(autohide_after) shows and auto-hides log messages.
  • hide_logs() hides log messages.
  • show_status([status], [progress]) shows status on running item.
  • clear_status() clears (and hides) status on item
  • touch([save=false]) updates (and optionally saves) time of item.
  • save() saves item.
  • start(async_func) starts async evaluation on item.
  • invoke(func) invokes function with item on the stack.
  • attach(func) attaches function to item by wrapping it with invoke.
  • attach(promise) attaches promise to item by wrapping then,catch,finally.
  • dispatch(func, [delay_ms]) dispatches attached function.
  • dispatch_task(name, func, [delay_ms, period_ms]) dispatches named task.
  • cancel_task(name) cancels named task.
  • pending_task(name) returns true if named task is pending completion.
  • promise(func) returns new attached promise with attached executor.
  • resolve(thing) returns new attached promise that resolves thing.
  • debug|info|log|warn|error(...) invokes attached console.*(...).
  • fatal(...) throws Error(...) including stack trace.
  • delay(ms) returns promise resolved after specified time.
  • images([options]) returns array of uploaded images.
  • invalidate_elem_cache() invalidates rendered element cache for item.
  • cached(key, value_function) returns cached value from item.cache.
  • invalidate_cache() invalidates cache for next access via item.cache.
  • validate_cache() validates cache for current item.deephash.
  • save_local_store() saves item.local_store to localStorage.
  • save_global_store() saves item.global_store to firebase.
