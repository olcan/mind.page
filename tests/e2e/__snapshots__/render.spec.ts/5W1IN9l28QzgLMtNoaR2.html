commands/restore command /restore [name|version] restores an existing or deleted item from a past version.

  • /restore lists valid names (id:<id>) for recently deleted items.
  • /restore name lists valid versions (version:…) for item name.
    • name can be existing item #label or id or deleted item id.
    • Labels are not available for deleted items due to encryption.
  • /restore version creates a new item with text from version.
    • Remove label #restored or copy text into existing item.
    • Copying text into existing item maintains its history.
    • Switching to new item splits history across items.
      • Older versions remain on older (deleted) items.
      • Unavoidable when recovering deleted items.
