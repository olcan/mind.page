MindPage/core/functions are:

  • load function for loading external libraries.
  • macros attached to window, e.g. html(content).
  • MindBox functions, e.g. set(text).
  • _item(name,[log_errors]) returns _Item with name (label or id).
  • _items([label]) returns array of _Items.
  • _exists(name,[allow_multiple]) returns true if item name exists.
  • _create(text,[options]) creates new item w/ given text.
  • _labels([selector]) returns array of labels matching optional selector.
  • _sublabels(parent) returns array of labels nested under parent label.
  • _host returns (canonical) hostname for client
  • _is_local(host) returns true if host is considered local
  • _modal opens modal confirmation/input prompts.
  • _delay(ms) returns promise resolved after specified time.
  • _update_dom() returns promise resolved after dom is up-to-date.
  • _scroll_to(y) scroll vertically to position y.
  • _encrypt(text) encrypts a (text) string.
  • _decrypt(text) decrypts an encrypted (text) string.
  • _encrypt_bytes(uint8array) encrypts an byte array.
  • _decrypt_bytes(uint8array) decrypts an encrypted byte array.
  • _encrypt_item(item) encrypts an item.
  • _decrypt_item(item) decrypts an encrypted item.
  • _render_item(item) renders an item.
  • _parse_tags(text) parses tags in text.
  • _parse_label(text) parses label in text.
  • _replace_tags(text, regex, replacer) replaces tags in text.
  • _resolve_tags(label, tags) resolves tags relative to label.
  • _resolve_tag(label, tag) resolves tag relative to label.
  • _special_tag(tag) returns if tag enables any features.
  • _extract_block(text, type) extracts block(s) in text.
  • _replace_block(text, type, replacer) replaces block(s) in text.
  • _stringify(x) converts x to a string.
  • _byte_stringify(x) converts x to a byte (binary) string.
  • _encode(string,[encoding='base64']) encodes string into encoding:
    • 'base64' string, 'utf8' string, 'utf8_array' (Uint8Array), or 'byte_array' (Uint8Array).
  • _decode(encoded,[encoding='base64']) decodes string from specified encoding.
  • _concat_byte_arrays(...arrays) concatenates byte arrays.
  • _hash(x,[hasher],[stringifier]) hashes x using hasher and stringifier. Default hasher is _hash_64_fnv1a (see below) and default stringifier is toString for functions and JSON.stringify for everything else. Returns integer (≤52-bit) or hex string (>52-bit) depending on hasher:
    • _hash_32_djb2(string) hashes using djb2 (xor variant).
    • _hash_32_fnv1a(string) hashes using 32-bit fnv-1a.
    • _hash_32_murmur3(string) hashes using 32-bit murmur v3.
    • _hash_52_fnv1a(string) hashes using 52-bit fnv-1a.
    • _hash_64_fnv1a(string) hashes using 64-bit fnv-1a.
    • _hash_128_murmur3_x64(string) hashes using 128-bit murmur v3 (x64 variant).
    • _hash_128_murmur3_x86(string) hashes using 128-bit murmur v3 (x86 variant).
    • _hash_160_sha1(string) hashes using 160-bit secure hash algo 1.
