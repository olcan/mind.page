mod (n,m) (n,m)

((n % m) + m) % m

is_flat (x) (x)

is x flat?


flat means uniform depth 1 or 0
non-array (depth 0) considered flat
undefined is considered non-array
is_rectangular (x) (x)

is x rectangular?


rectangular means uniform depth
non-array (depth 0) considered rectangular
many functions below assume x is rectangular
dimensions (x) (x)

dimensions of rectangular x


invalid for non-rectangular x

depth (x) (x)

depth of rectangular x


invalid for non-rectangular x

is_scalar (x) (x)

!is_array(x) // ≡ depth(x)==0

is_matrix (x) (x)

depth(x) == 2 for rectangular x


invalid for non-rectangular x

matrix ( [J],[K],[x] ) ( [J = 0],[K = 0],[x] )

matrix xJK of dimensions J,K


x can be given to fill as xJK[j][k]=x ∀j,k
x can be a function of indices, e.g. (j,k)=>j*k

scalarify (x) (x)

peels away outer arrays of length 1


does not affect longer arrays
matrixify (x) (x)

wraps scalar → array → 1×n matrix


does not affect deeper arrays
assumes rectangular x

transpose (xJK) (xJK)

transposes matrix xJK → xKJ


matrixifies scalar/vector argument as needed
row type matches that of argument
dot (xJZ,yKZ) (xJZ,yKZ)

dot product xJZ.transpose(yKZ)


multiplies rows into rows (not rows into columns)
matrixifies scalar/vector arguments as needed
row type matches that of first argument
