TensorFlow/vis is the official Visualization Library for TensorFlow. Keyboard shortcuts ` (toggle visor) and ⇧` (=~, to toggle maximize once open) can be used to toggle the "visor" (sidebar) once library is loaded. Macro <<visor_toggle>> (defined below) can also be used to render a toggle link in items. See basic example and linear_regression tutorial.

}
