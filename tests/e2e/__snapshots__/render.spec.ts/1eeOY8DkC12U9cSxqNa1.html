features/_async tag enables async evaluation.

  • Code is wrapped as _this.start(async()=>{ ... })
  • Code must explicitly return any output.
  • Code must await on promises to avoid premature return.
  • Default log attribution is time-based (vs stack-based).
    • Allows easy tracking of logs from external libraries.
    • Upon return, logs are written into item via write_log.
    • Log options can be configured via _this.log_options.
  • Item may not be on the stack for entire async evaluation.
    • Item is always on stack for top-level async function call.
    • Helper functions can bring item back on stack as needed.
      • invoke, attach, dispatch, promise, resolve, ...
      • For logging: debug, info, log, warn, error
    • _this is still available from lexical context of item.
  • Async evaluation is propagated to dependents .
    • For example, see mathjs/example.
