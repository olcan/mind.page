util/core/hash defines hashing and encoding/decoding utilities or aliases.

hash (x,[hasher],[stringifier] ) (x,[hasher = _hash_64_fnv1a],[stringifier] )

hashes x using hasher


applies stringifier to non-string x
integer for ≤52 bits, hex string for >52
hasher bits algorithm
_hash_32_djb2 32 djb2 (xor)
_hash_32_fnv1a 32 fnv-1a
_hash_32_murmur3 32 murmur v3
_hash_52_fnv1a 52 fnv-1a
default ➡ _hash_64_fnv1a 64 fnv-1a
_hash_128_murmur3_x86 128 murmur v3 x86
_hash_128_murmur3_x64 128 murmur v3 x64
_hash_160_sha1 160 secure hash algo 1
encode (string,[encoding] ) (string,[encoding = 'base64'] )

encodes string into encoding


string is assumed UTF-16 (js default)
'utf8' UTF-8 string
'utf8_array' UTF-8 array (Uint8Array)
'byte_array' raw byte array (Uint8Array) for code points ≤255 only
default ➡ 'base64' Base64 ASCII string
decode (x,[encoding] ) (x,[encoding = 'base64'] )

decodes string from x in encoding


see encode for supported encodings
byte_stringify (buffer|view) (buffer|view)

convert ArrayBuffer or view to byte string


byte strings (a.k.a. "binary") encode 8-bit binary numbers using code points ≤255
in contrast, regular strings in js encode unicode characters in UTF-16

hex_stringify (buffer|view) (buffer|view)

convert ArrayBuffer or view to hex string


each byte is 0-padded to 2 digits, e.g. [0,255] → 00ff
