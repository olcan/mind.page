#### Heading 2
has auto-generated id `heading-2`

Fragment (`#id`) links work when the target element is on the page. An extra '#' is used to distinguish from `#tags`:
- [Scroll to Heading 1](##heading-1)
- [Scroll to Heading 2](##heading-2)

Checkboxes `[ ]` and `[x]` work inside bullets:
- [ ] do
- [ ] not
- [ ] quite work
