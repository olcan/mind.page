#markdown/code_blocks 

code can be `inline` or

```
in a multi-line
code block
```

    or just indented    
      with spaces

or interleaved with regular text

\`backticks\` can be escaped as `` \` ``
`` double `backtick` spans are also supported ``

alternative multi-line delimiters are not supported (e.g. see https://stackoverflow.com/a/31834381)
